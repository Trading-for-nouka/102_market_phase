# 📊 102_market_phase — 市場フェーズ判定

日経・TOPIX・VIX・先物・ドル円などを総合スコアリングし、
現在の市場フェーズを判定して Discord に通知、`market_phase.json` をリポジトリに保存します。
他の戦略リポジトリ（201〜204）はこのファイルを参照してエントリー可否を判断します。

## フェーズ一覧

| フェーズ | 意味 |
|---|---|
| `BULL` | 積極運用相場 |
| `NEUTRAL` | 方向感なし・選別投資 |
| `REBOUND` | 底打ち反転の兆し |
| `RISK_OFF` | 地合い悪化・守り優先 |
| `WARN` | CRASH 予備軍（スコア 2/7、または直近 7 日以内に CRASH を観測） |
| `CRASH` | パニック相場（スコア 3/7 以上） |

## CRASHスコア判定条件（7項目）

| # | 条件 | 閾値 |
|---|---|---|
| 1 | S&P500 日次下落 | -3% 超 |
| 2 | VIX 水準 | 30 超 |
| 3 | VIX 週次急騰 | 5営業日前比 +40% 超 |
| 4 | 日経先物 日次下落 | -3% 超 |
| 5 | 円高急進 | 日次 -1.5% 超 |
| 6 | ボラティリティ急増 | 5日標準偏差 > 60日標準偏差 × 2 |
| 7 | 中期累積下落 | 10営業日で -8% 超（じわじわ下落対応） |

3点以上で `CRASH`、2点で `WARN`。

### 検証の限界

- ADR は N225 単体の上昇日数/下落日数で近似（本番は universe496.csv 全銘柄）

- バックテストは過去データへの検証であり、将来の精度を保証するものではありません
